# Quest Manager (2D)

Нативное Android-приложение для панели Quest 3S. Это отдельный APK от XR baseline.
Данные читает доверенный ПК через ADB; приложение на шлеме общается с ним по `adb reverse`.
Диагностика сохраняется на ПК в `.local/diagnostics-*.jsonl`.
Интерфейс рисуется в Android Bitmap и выводится через нативную Vulkan-поверхность.
Широкое окно показывает планшетную панель. В узком окне интерфейс перестраивает вкладки,
карточки и список процессов под доступную ширину и прокручивается по вертикали без
растягивания текста. Если Vulkan недоступен, запускается резервный Compose-экран.
Для управления 2D-панелью доступны указатель контроллера и триггер (нажатие и
перетаскивание), стик или колесо (прокрутка), D-pad (выбор вкладок и строк),
A/Enter (подтверждение), B/Esc (отмена диалога). Фокус подсвечивается. Работа
физических контроллеров в окне Horizon OS проверяется отдельно на шлеме.

## Сборка и запуск

Из корня проекта:

```powershell
.\gradlew.bat :app:assembleDebug
adb install -r .\app\build\outputs\apk\debug\app-debug.apk
powershell -ExecutionPolicy Bypass -File .\bridge.ps1
```

При нескольких ADB-устройствах укажите `-Serial <серийный-номер>`. Пока работает мост,
ПК должен быть подключён к шлему через USB или Wi-Fi ADB. После перезагрузки шлема
мост запускается заново.
После переустановки APK при уже работающем мосте при необходимости восстановите
`adb reverse tcp:18765 tcp:18765` для выбранного шлема.

Широкая 2D-панель имеет разделы «Показатели», «Процессы» и «Устройство». «⋮» без рамки
в конце каждой строки открывает меню действий. «Подробнее» показывает страницу
поверх текущего раздела с кнопкой «Назад»; раздел и прокрутка списка сохраняются.
Панель обновляет
CPU, GPU и RAM каждые 3 секунды, пока окно открыто; показывает загрузку каждого ядра и
память, выделенную GPU, по процессам. CPU 100% означает полную загрузку всех ядер за интервал,
GPU 100% — работу GPU в течение всего интервала. Память, выделенная GPU, входит в общую RAM
и может учитываться в RSS. Эти значения не складываются; отдельной шкалы «VRAM 100%» нет.
Таблица показывает сторонние и системные пакеты, отдельные работающие процессы,
PID, PSS, RSS и GPU-выделения; поиск работает по имени и PID. Разбивка RAM на
PSS процессов, ядро и ZRAM снимается при обновлении списка. RSS и GPU-выделения
не прибавляются к PSS; `MemAvailable` учитывает освобождаемую память.
Для сторонних пакетов доступны «Остановить» (`am force-stop`), «Перезапустить»
(`force-stop` и запуск Activity), «Запретить запуск» (`pm suspend`) и «Разрешить
запуск» (`pm unsuspend`). Каждое действие требует подтверждения; мост перечитывает
состояние и записывает результат в JSONL на ПК. `pm suspend` ограничивает открытие
приложения и не означает глубокий сон. Системные пакеты и процессы доступны только
для просмотра. Произвольных ADB-команд через приложение нет. Изменяющие действия
нужно отдельно проверить на подходящем тестовом APK; сборка, установка и чтение
состояния уже проверены на Quest 3S.
